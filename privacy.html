개인정보처리방침

최종 업데이트: 2026-10-28

이 문서는 rclone-drive-z라는 로컬 Windows 설정이 Google 계정 데이터를 어떻게 사용하는지 설명합니다. 이 설정은 rclone을 이용해 Google Drive에서 공유받은 폴더 하나를 네트워크 드라이브로 연결합니다. 별도의 앱 서버는 제공하지 않습니다.

중요한 권한 범위
이 설정은 https://www.googleapis.com/auth/drive OAuth 범위를 요청합니다. 이 범위는 승인한 계정의 Drive 파일 전체에 대한 읽기·쓰기 권한을 허용할 수 있으며, Z:에 표시되는 공유 폴더 하나로 OAuth 권한 자체가 제한되지는 않습니다. rclone 설정은 선택된 공유 폴더를 마운트하지만, 계정 소유자는 Google 동의 화면에서 요청 범위를 직접 확인하고 승인해야 합니다.

처리하는 데이터

  • 승인한 Google 계정의 Drive 파일 이름, 메타데이터 및 파일 내용. rclone은 Drive API로 파일을 조회·다운로드·업로드·수정·삭제할 수 있습니다. 실제 작업은 계정 동의와 파일·폴더 권한에 따릅니다.
  • OAuth 인증 토큰과 연결 설정. rclone 설정 파일에 로컬 저장됩니다.
  • 파일 작업용 로컬 VFS 캐시. 파일 내용의 임시 사본이 포함될 수 있습니다.
  • 자동 실행을 사용하면 로그가 %LOCALAPPDATA%\RcloneDriveSetup\mount.log에 저장됩니다. 로그에 오류와 파일 경로가 포함될 수 있습니다.

이용 목적과 전송

이 안내 페이지가 GitHub Pages에 게시되면 GitHub가 웹사이트 방문 요청을 처리할 수 있으며, 이 처리에는 GitHub의 개인정보 보호 정책이 적용됩니다. Google Drive 파일과 OAuth 토큰은 이 안내 웹사이트에 업로드되지 않습니다.

데이터는 사용자가 선택한 Drive 공유 폴더를 PC에서 보고 파일을 복사하거나 변경하기 위해 처리됩니다. rclone은 해당 PC에서 Google Drive API와 직접 통신합니다. 이 설정의 운영자는 Drive 파일이나 OAuth 토큰을 수신하지 않습니다. Google API 요청은 Google 서비스에서 처리되며 Google의 약관과 개인정보 보호 정책이 적용됩니다. 이 설정은 Drive 데이터를 광고나 분석 목적으로 사용하지 않습니다.

저장 및 보유 기간

OAuth 설정 파일, 로그 및 캐시는 사용자의 Windows PC에 저장됩니다. 인증 설정과 로그는 사용자가 삭제할 때까지 남을 수 있습니다. 캐시는 rclone 설정에 따라 관리됩니다. 캐시를 지우기 전에 rclone을 종료하고 열려 있는 파일을 저장했으며 업로드가 끝났는지 확인해야 합니다.

사용자 선택

  • Google 계정 보안 설정에서 rclone 접근 권한을 취소할 수 있습니다.
  • rclone을 종료하고 업로드가 끝난 뒤 이 PC의 rclone 설정·캐시·로그를 삭제할 수 있습니다.
  • 공유 폴더 접근과 편집 권한은 Google Drive 공유 설정에서 관리합니다.

문의

이 설정에 대한 문의는 Google OAuth 동의 화면에 표시된 사용자 지원 이메일로 연락해 주세요.

Privacy Policy

Last updated: 2026-10-28

rclone-drive-z is a local Windows setup that uses rclone to mount one folder shared through Google Drive. It does not operate a separate app server.

Data and permissions

This setup requests https://www.googleapis.com/auth/drive. This scope can permit read and write access across the authorizing Google account's Drive; it is not restricted to the folder displayed on Z:. rclone mounts the selected shared folder, and the account holder reviews and approves the requested scope on Google's consent screen. Actual operations also depend on the account's Google Drive permissions.

rclone processes Drive file names, metadata, and contents to list, download, upload, modify, or delete files. OAuth settings are stored in the local rclone configuration file. A local VFS cache may contain temporary file copies. When the provided autostart is used, the mount log is stored at %LOCALAPPDATA%\RcloneDriveSetup\mount.log and may include errors and file paths.

Use, sharing, and retention

If this information page is published on GitHub Pages, GitHub may process website visit requests under its own privacy policy. Google Drive files and OAuth tokens are not uploaded to this information website.

rclone communicates directly from the user's Windows PC with the Google Drive API. The app operator does not receive Drive files or OAuth tokens. Drive data is not used for advertising or analytics by this setup. Google processes API requests under Google's own terms and privacy policy.

Local configuration and logs may remain until removed. rclone manages the cache according to its settings; stop rclone and confirm uploads are complete before removing cache files.

Choices and contact

The user can revoke rclone access in Google Account security settings and remove local configuration, cache, and logs after stopping rclone. Sharing and editing permissions are managed in Google Drive. For support, use the user support email shown on the Google OAuth consent screen.
